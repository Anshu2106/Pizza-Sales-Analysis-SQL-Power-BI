# Pizza Sales Analysis Using SQL & Power-BI
SQL & Power BI project analyzing pizza sales, orders, product performance, categories, sizes, and sales trends using data analysis and interactive visualization.

## 📌 Project Overview

This project is a Pizza Sales Data Analysis project using SQL and Power BI. The objective is to analyze pizza sales data, understand customer ordering patterns, evaluate product and category performance, and present the findings through an interactive Power BI dashboard.

The project combines SQL-based data analysis with Power BI visualization to transform transactional pizza sales data into useful business insights.

## 🎯 Project Objectives

- Analyze overall pizza sales and revenue.
- Understand order and quantity trends.
- Compare pizza categories and sizes.
- Identify top-performing pizzas.
- Analyze sales patterns across dates and times.
- Evaluate product-level performance using quantity, unit price, and total price.
- Use SQL to answer business questions from transactional data.
- Build an interactive Power BI dashboard to present the analysis clearly.

## 📂 Dataset

The project uses a pizza sales dataset containing 48,605 records and 12 columns.

- Pizza_id - Unique identifier for each pizza record.
- Order_id - Identifier of the customer order.
- Pizza_Name_id - Identifier for the pizza product.
- Quantity - Quantity of pizzas ordered.
- Order_Date - Date of the order.
- Order_Time - Time of the order.
- Unit_Price - Price per pizza.
- Total_Price - Total price for the record.
- Pizza_Size - Size of the pizza.
- Pizza_Category - Category of the Pizza.
- Pizza_Name - Name of the pizza.
- Pizza_Ingredients - Ingredients used in the pizza.

The dataset covers orders from January 1, 2025 to December 31, 2025, with 21,334 unique orders and 32 unique pizza products.

## 📊 Dataset Summary

## 🔍 Analysis Performed

**1. Sales Analysis**

The project analyzes:

- Total sales value.
- Total quantity sold.
- Number of orders.
- Sales by date.
- Sales by month and other time periods.
- Revenue contribution across products and categories.

**2. Product Analysis**

Product-level analysis is used to identify:

- Best-selling pizzas.
- Pizza products generating higher sales.
- Quantity sold by pizza.
- Price differences across products.
- Performance of individual pizza products.

**3. Category Analysis**

Pizza performance is compared across:

- Classic
- Supreme
- Veggie
- Chicken

This helps understand which categories contribute more to overall order quantity and sales.

**4. Size Analysis**

The project compares pizza sales across different sizes to understand:

- Which sizes are ordered more frequently.
- Quantity contribution by size.
- Sales performance across pizza sizes.

**5. Time-Based Analysis**

Order date and time fields are used to analyze:

- Daily sales trends.
- Monthly performance.
- Ordering patterns across time.
- Periods with higher order activity.
